# Laptop Hardware Servicing & Restoration — Acer TravelMate P245M

## Overview

Full teardown, cleaning, and upgrade of an Acer TravelMate P245M that had slowed to a crawl — slow boot, constant resource bottlenecking — restoring it to a fully functional daily-use Windows 10 machine.

## Initial condition

Slow boot, heavy resource bottleneck. Still usable, but frustrating for daily use.

## What I did

- Opened the casing and performed a full teardown
- Deep-cleaned accumulated dust
- Removed dried, degraded thermal paste from the CPU and heatsink and repasted with Arctic MX-6
- Replaced the keyboard
- Replaced the cooling fan (model: DFS531005PL0T FC8X)
- Upgraded RAM and storage (below)
- Re-sealed the plastic chassis rivets after reopening the case

## Parts

| Component | Before | After |
|---|---|---|
| RAM | 1× ADATA 4GB 1Rx8 PC3L-12800S-11 | + 1× Samsung 4GB 1Rx8 PC3L-12800S-11-13-B4 (8GB DDR3L total) |
| Storage | Seagate 500GB Momentus Thin HDD | ORICO 128GB Y-20 SSD |
| Keyboard | Original (failing) | Replacement unit |
| Cooling fan | Original | DFS531005PL0T FC8X |

## Problems encountered

- **Deformed screw heads** on the original screws, from age/prior servicing
- **Re-seating the keyboard** after replacing worn-out plastic retaining rivets
- Making sure proper **anti-static/insulating tape** was in place before reassembly

## How I diagnosed and fixed it

Booted the machine and observed its behavior before opening it up, to confirm the bottleneck was hardware (RAM/storage), not software. Since this exact model isn't a common one, I researched model-specific teardown guides before opening the case, to avoid damaging clips or connectors that weren't visible from the outside.

## Result

Fully functional Windows 10 installation, single-partition 128GB SSD, 8GB DDR3L RAM, and a properly working keyboard.
